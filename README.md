## 📱 PWA Support

The portfolio is being enhanced as a Progressive Web App, allowing visitors to install it on supported devices.

PWA components include:

- `manifest.json` — application metadata and icons
- `sw.js` — service worker and caching
- `icons/` — application icons
- `index.html` — website and PWA integration

Some features may require an internet connection. Offline functionality depends on which resources have been cached.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Rudra0-rudy/portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio
   ```

3. Run the website using a local development server, such as the VS Code Live Server extension.

> A local HTTP server is recommended for testing service workers. Opening `index.html` directly as a file will not fully test PWA functionality.

## 🧪 PWA Testing

- Verify the web app manifest in browser developer tools.
- Check service worker registration.
- Test installation on supported mobile devices.
- Test cached resources while offline.
- Check the website using Lighthouse.
